# waymaker-cli

The `wm` binary of [Waymaker](https://github.com/felipecm-br/waymaker), a terminal fuzzy finder: config loading and layering, presets, the file-manager and reload actions, and the handlers it registers on [`waymaker-lib`](../waymaker-lib/README.md).

See the [repository README](../README.md) for installation and usage, and `wm --doc <page>` (sources in [`assets/docs/`](assets/docs/)) for the guide. Licensed under [AGPL-3.0-or-later](LICENSE).
